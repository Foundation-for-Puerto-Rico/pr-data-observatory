Global Innovation Index: Puerto Rico country profile

In 2021 the Centro de Innovación of Foundation for Puerto Rico (FPR) placed Puerto Rico among the 131 economies of the Global Innovation Index 2020, indicator by indicator, with the index's own method. This page keeps that profile exactly as it was published and shows, beside each indicator, the newest value that an open source publishes for Puerto Rico.

FPR's calculation, not an official ranking. Puerto Rico is not one of the economies of the official Global Innovation Index. The ranks are FPR's: they place Puerto Rico's value among the GII 2020 values of each indicator. The index and its method are the work of Cornell University, INSEAD and the World Intellectual Property Organization (WIPO). The profile has no overall score or rank, and this page computes none.

info2 · How to read it

Values and ranks of 2021. They are the profile as published: the raw value of each indicator and its rank, printed "x / 132" (the 131 economies of the GII 2020 plus Puerto Rico). Many indicators had data for fewer economies; an open indicator gives that number. A re-check with FPR's working file reproduces 44 of the 56 printed ranks. Four ranks that counted missing data as zero carry a correction, and six values that differ from the working file carry a note; the printed value and rank are kept.
Updated values. The newest value that an open source publishes for Puerto Rico, with its year and a link to the source. The 2021 ranks compare Puerto Rico with the GII 2020 economies, so a newer value is not ranked among them. A value marked "FPR estimate" applies FPR's method to open data. The arrow beside it compares it with the 2021 value in the direction of the GII's scale: green when it is better, red when it is worse, "≈" when the change is smaller than 5% of the interquartile range of the GII 2026 economies for that indicator, and "—" when the two were measured differently. For the three World Bank governance indicators, whose every release revises all past years, the arrow compares two years of the current release (2018, the data year the GII 2020 used, and the latest); the printed value is kept as published.
Position in the GII 2026 (indicative). For the indicators whose Puerto Rico source and definition match the Global Innovation Index 2026, the last column says where Puerto Rico's updated value would fall among the GII 2026 economies with data, written X/N like the profile: X is 1 plus the number of economies with a strictly better value (ties share the better place, as in WIPO's own ranks) and N counts those economies plus Puerto Rico. Ranking the value gives the same place as ranking the GII's 0-100 score, because min-max normalization and the log transform keep the order; where the GII winsorizes, no position is given beyond the capped values. It is FPR's calculation, indicative, and not an official WIPO rank (†). No pillar, sub-index or overall score is computed: Puerto Rico has comparable data for too few indicators to meet the GII's coverage rule.
Not updated. An open indicator says why: the source was discontinued, it does not cover Puerto Rico, its data are proprietary, its only source needs an API key, or a file still has to be read by hand. The values from IHS Markit, Web of Science and Brand Finance are shown as FPR published them in 2021; their sources are proprietary and are not updated here.
